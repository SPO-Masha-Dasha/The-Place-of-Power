# The Place of Power

Текстовая пошаговая RPG игра в стиле "Звёздных Войн", где команда героев сражается с могущественным боссом.

## Как играть

1. Запустите файл `main.py` в PyCharm
2. Следуйте инструкциям на экране
3. Выбирайте действия для героев в бою

## Персонажи

### Герои:
- **Люк Скайуокер** - атака и защита
- **Мастер Йода** - поддержка и контроль  
- **R2-D2** - техника и урон

### Босс:
- **Дарт Вейдер** - 5 фаз с разным поведением

## Особенности

- Пошаговый бой с выбором действий
- Уникальные способности каждого персонажа
- Система эффектов и предметов
- Стратегический геймплей

---

*Для запуска: откройте main.py в PyCharm и нажмите "Run"*
